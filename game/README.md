# NRS Unity Game Client

This directory will contain the Unity Android project.

The client is responsible for presentation, input, camera, local prediction/interpolation and communicating with the authoritative game server.

Do not put authoritative economy, ownership, job completion or reward logic in the client.

## Target

Android first, including low-memory devices around the 3 GB RAM class.

## First playable slice

The client must eventually support the Stage 1/2 laboratory flow defined in `docs/ROADMAP.md`.
